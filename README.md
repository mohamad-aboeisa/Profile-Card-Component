# Profile Card Component

A profile card component created while practicing HTML, CSS, SVG, and CSS animations. The project focuses on building a clean and modern UI component with smooth visual effects and responsive styling.

Through this project, I practiced working with animations, SVG graphics, positioning, layout techniques, and reusable component structure to improve front-end development skills.

## Technologies Used
- HTML5
- CSS3
- CSS Animations
- SVG
